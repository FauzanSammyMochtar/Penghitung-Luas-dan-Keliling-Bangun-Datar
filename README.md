# Penghitung Luas dan Keliling Bangun Datar 

## Deskripsi
Proyek sederhana untuk menghitung Luas dan Keliling dari:

1. Lingkaran
2. Persegi panjang 
3. Segitiga 

## Persyaratan
* C Compiler (Seperti GCC/Clang)

## Cara Menggunakan
1. Unduh atau clone repositori ini:
git clone https://github.com/FauzanSammyMochtar/Penghitung-Luas-dan-Keliling-Bangun-Datar.git

2. Masuk ke folder proyek:
cd Penghitung-Luas-dan-Keliling-Bangun-Datar

3. Compile program:
clang penghitung_luas_dan_keliling_bangun_datar.c -o penghitung_luas_dan_keliling_bangun_datar

4. Jalankan program:
./penghitung_luas_dan_keliling_bangun_datar
