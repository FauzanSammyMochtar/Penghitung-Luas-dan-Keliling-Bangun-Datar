# Penghituang Luas dan Keliling Bangun Datar 

## Deskripsi
Proyek sederhana untuk menghitung Luas dan Keliling dari:

1. Lingkaran
2. Persegi panjang 
3. Segitiga 

## Persyaratan
* C Compiler (Seperti GCC/Clang)

## Cara Menggunakan
1. Unduh atau clone repositori ini:
git clone https://github.com/FauzanSammyMochtar/Penghitung-Luas-dan-Keliling-Bangun-Datar.git

2. Masuk ke folder proyek:
cd Penghitung-Luas-dan-Keliling-Bangun-Datar

3. Jalankan program:
clang
